Отчёт по заданию

Задание: на представленных картинках распознать доминошки и подсчитать количество точек на них

Выполнение задание оформлено в GitHub в виде программы на ЯП Python - main.py
Все зависимости, которые были установлены и использованы при выполнении задания указаны в файле requirements.txt
В папке train_data исходные фотографии
В папке train_data_result размечены треугольники и указано количество точек

Отчёт включает себя выбор инструментов, этапы работы, оценку выполненного задания

Выбор инструментов:

    1. Язык программирования - Python.
        Простой в обращении, со множеством библиотек для разных задач

    2. OpenCV - открытая библиотека для работы с алгоритмами компьютерного зрения

Этапы работы:

    1. Визуальная оценка фотографий
        Доминошки, которые необходимо распознать, можно аппроксимировать треугольниками

    2. Простейшее выделение контуров
        Программа находит базовые контуры, в которых теоретически могут оказаться треугольники
        Проблемы: выделение контуров, которые не являются треугольниками и пропуск контуров самих треугольников

    3. Преобразование данных картинок
        Удаление шумов с помощью комбинации Гауссовского и медианного размытий
        Более точное нахождение контуров, меньше ложных срабатываний
        Проблемы: определение, что контур является доминошкой

    4. Выделение из найденных контуров треугольников
        Аппроксимация контуров с помощью многоульников
        Выбор многоугольников с количеством углов, равным 3
        Проблемы: некоторые многоугольники достаточно точно определяли доминошку, но их апроксимация не являлась треугольником

    5. Подбор параметров для каждой картинки, при которой находилось максимальное количество треугольников
        Разбитие программы на функции. 
        Нахождение большего количества треугольников, чем при фиксированных параметрах размытий картинки(удаления шумов)
        На expert_train находилось также маленькое количество трегульников, вдобавок появлялись лишние треугольники, которые не относились к доминошкам 

    6. Нахождение точек на доминошках
        Размытие фотографии, поиск простых связных областей

Оценка выполненного задания:

    1. Детекция доминошек на "тренировочных данных" - 6/10
        Почти все доминошки апроксимировались треугольниками, но 100% результата достичь не удалось
        Доминошки, которые не апроксимировались треугольниками, имели не очень сильные расхождения от треугольников, но программа их не определяла

    2. Детекция доминошек на expert_train - 2.5/10
        Апроксимировалась треугольниками лишь малая часть доминошек, возникали треугольники, которые определяли объект, не являющийся доминошкой

    3. Детекция точек - 1.5/10
        Не удалось написать программу, которая хорошо детектить треугольники
